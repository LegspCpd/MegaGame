fix(installer): correct ISPP constant expansion (found by local repro)

CI kept failing with a bare "The system cannot find the path specified."
and no script line, so the problem was reproduced locally: Inno Setup
6.7.3 installed to C:\is and ISCC run with the exact same arguments.

The path handling was fine; two constants were not. ISPP resolves {#Name} as
a string expansion, so nesting one inside another --

  #define AppVersion "{#MyAppVersion}"

yields "Unknown constant #MyAppVersion" (line 30). After fixing that a second
problem surfaced: AppExeName had been dropped from the header while still
being used by [Icons] and [Run].

Both are fixed, and PrivilegesRequired=lowest now matches the HKCU entries so
Inno stops warning about per-user writes in an elevated install.

Verified locally: "Successful compile" with zero warnings, producing
MegaGame-Setup-v1.0.199.exe (2 MB).
